# Student Management System

A web-based Student Management System built with **Java, JSP, Servlets, Maven, MySQL, and Python Flask**. The Java web application provides student and course management workflows, while the Python module provides API endpoints and analytics.

**Repository:** https://github.com/abhishek808319/Student-Management-System

## Overview

This academic mini-project combines a Java web application with a separate Flask service. It demonstrates CRUD operations, database connectivity, web development, API integration, and student performance analysis.

## Features

### Java Web Application
- Add, view, edit, and manage student records.
- View student profiles.
- Manage courses.
- Record and view attendance.
- Manage student marks.
- Archive and restore student records.
- Activity logging.
- Maven project structure suitable for Eclipse and a servlet container.

### Python Flask Module
- Flask API for application-related operations.
- MySQL database connectivity.
- Course, attendance, and marks-related API functionality.
- Student performance analytics using Pandas and NumPy.
- Quick Sort and Merge Sort ranking comparisons.
- Performance charts generated by the analytics script.

Review `sms_python_module/app.py` for the exact API endpoints.

## Database Setup

1. Start MySQL Server.
2. Create the database:

   ```sql
   CREATE DATABASE student_management;
   ```

3. Create the tables expected by the DAO classes and Flask endpoints. Use your project's schema if available.
4. Create or select a MySQL account with access to `student_management`.
5. Configure the database connection with environment variables.

This repository README does not include a database dump. Do not import real student records into a public repository. If you add a schema file later, include table definitions and synthetic sample data only.

### Database environment variables

The Java connection class reads:
- `SMS_DB_USER` — database username; defaults to `root` if not set.
- `SMS_DB_PASSWORD` — database password; required.

Confirm that `sms_python_module/db.py` uses the same variable names before running the Flask service.

On Windows PowerShell, set variables for the current terminal session:

```powershell
$env:SMS_DB_USER = "root"
$env:SMS_DB_PASSWORD = "YOUR_LOCAL_MYSQL_PASSWORD"
```

Replace the example value locally. Never commit passwords or share them in screenshots or source code.

## Run the Java Web Application

1. Clone the repository:

   ```bash
   git clone https://github.com/abhishek808319/Student-Management-System.git
   cd Student-Management-System
   ```

2. In Eclipse, select **File → Import → Existing Maven Projects**, choose the cloned project folder, and finish the import.
3. Configure MySQL and set `SMS_DB_USER` and `SMS_DB_PASSWORD` in the environment available to Eclipse.
4. Confirm the MySQL Connector/J dependency is present in `pom.xml`.
5. Configure the project with your local Tomcat installation and run it on the server.

The original local setup used this URL:

```text
http://localhost:8082/StudentManagementSystem/
```

Your port and context path may differ; use the URL shown by Eclipse/Tomcat.

## Run the Python Flask Module

Open PowerShell from the repository root:

```powershell
cd sms_python_module
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Set the database variables in the same terminal:

```powershell
$env:SMS_DB_USER = "root"
$env:SMS_DB_PASSWORD = "YOUR_LOCAL_MYSQL_PASSWORD"
```

Start Flask:

```powershell
python app.py
```

Check the terminal output for the host and port. Confirm the exact API paths in `app.py`. Do not assume the service is accessible from another device unless host, firewall, and CORS settings are configured accordingly.

To run analytics, ensure the database schema and required records exist, then run:

```powershell
python analytics.py
```

The script may generate chart images locally.

## Configuration and Security

- Never commit `.env` files, passwords, API keys, Telegram bot tokens, or other credentials.
- Do not commit `venv/`, `.venv/`, `__pycache__/`, compiled files, or local IDE secrets.
- Do not upload production database dumps or personally identifiable student records.
- Use environment variables or a local ignored configuration file for secrets.
- If a credential was committed previously, changing the current source file is not enough. Rotate the credential and clean it from Git history before treating the public repository as safe.
- Use synthetic data for demonstrations and screenshots.

## Troubleshooting

- **Database connection error:** Confirm MySQL is running, the database and expected tables exist, and the environment variables are set for the process.
- **JDBC driver error:** Check the MySQL Connector/J dependency in `pom.xml` and refresh Maven dependencies.
- **Tomcat deployment issue:** Check Tomcat compatibility with the project's servlet dependencies and review the Eclipse Console.
- **Flask dependency error:** Activate the virtual environment and run `pip install -r requirements.txt`.
- **API connection issue:** Check Flask startup output, endpoint paths in `app.py`, and browser/network errors.
